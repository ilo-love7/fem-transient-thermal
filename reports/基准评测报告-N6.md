> 报告版本：v1.0.0（§1–§5）+ v1.1.0 深化（§6–§9，2026-11-10）+ v1.2.0 深化（§10–§12，2026-11-11）
> 环境：Windows / Python 3.12.10 / NumPy 2.5.4 / SciPy 1.18.1 / scikit-fem 12.0.2 / Matplotlib 3.11.2，纯 CPU

## 摘要

从零实现二维 Galerkin 有限元瞬态热传导求解器（多层结构、Robin 对流、脉冲体积热源、θ 法时间积分），并建立**解析解 / 第三方 FEM / 精细 Cauer 热阻网络 / 单节集总 Cauer** 四重交叉验证。

核心结果：

1. **装配正确性**：手写 FEM 与 scikit-fem 12 独立装配的稳态温度场逐位一致（最大节点差 **9.7e-11 K**）；与一维解析解差 **8.4e-4 K**；稳态能量守恒相对误差 **3.5e-13**。
2. **提案目标达成**：FEM 与精细 Cauer 网络在脉冲激励下的结温曲线**峰值温升误差 0.065%、摆幅误差 0.181%**，远优于提案「与热阻网络解析解误差 <5%」的目标。
3. **数值方法收敛阶**：时间后向 Euler `p=1.02`（理论 1）、Crank–Nicolson `p=2.01`（理论 2）、空间几何相似加密 `p=2.03`（理论 2）。
4. **口径发现**：芯片层为均匀体积热源时，朴素串联热阻公式高估结温 **0.3462 K**（层内热流线性递减使该层等效热阻减半）。
5. **工程结论**：基准工况热阻由对流主导（82.08%）；组合强化方案把周期稳态结温峰值从 82.41 °C 压到 **41.26 °C（−49.9%）**。
6. **适用边界**：一维集总 Cauer 网络在慢脉冲（T≥0.1 s）下误差 <3%，但在快脉冲（T=0.02 s）下摆幅误差 8.8%；二维局部热源 w/W=0.2 时因扩散热阻占 31.1% 而**低估结温 22.84 K**。

**v1.2 深化（§10–§12，2026-11-11）速览**：回应三个未做项，新增 3 模块 / 4 脚本 / 35 项单测（累计 68 项）。① **k(T) 瞬态 Newton**（完整切线）比欠松弛 Picard 少 7.2× 迭代，常功率终值与 v1.1 稳态 Picard 差 1.13e-4 K；发现 `1ᵀR ≡ ΔU/Δt + Q_conv − Q_in`，残差求和即能量失衡，截断迭代放大 2×10¹² 倍。② **动态扩散 RC 极点**：单极点预设**被证伪**（τ_best 跨周期漂移 17.06×、留一摆幅误差 47.78%），快脉冲绝对误差虽降 35–36% 但由高估翻为低估，1% 有效边界仍停在 T=0.2 s → 需多极点/分布参数模型。③ **辐射与接触热阻**：`h_rad≈5.4 W/(m²K)` 使强制对流下辐射占比 ≤1.06%（伪需求），但自然对流可达 61%；环境温度处线性化最多高估结温 171.47 K；接触热阻的边际代价是 TIM 本体优化的 **27.78 倍**，临界 `r_c''=3.60e-5 m²K/W`。工程侧把逐单元装配改为几何缓存，全量单测 41.8 s → 18.7 s。

## §1 物理模型与数值方法

### 1.1 控制方程与边界

二维单位厚度模型（所有功率以线密度 W/m 给定）：

```
ρc ∂T/∂t = ∇·(k ∇T) + q'''(x, y, t)
底面 y=0： -k ∂T/∂n = h (T − T_amb)      （Robin 对流）
顶面 y=H、左右侧面：绝热（自然边界）
```

三层结构自底向上：Cu 基板（1.0 mm, k=400, ρc=3.45e6）、TIM（0.2 mm, k=5, ρc=2.0e6）、Si 芯片（0.3 mm, k=130, ρc=1.65e6）；宽度 10 mm，`P'=3000 W/m`，`h=5000 W/(m²K)`，`T_amb=25 °C`。热源位于芯片层中心区域，`heat_source_width=W` 时退化为严格一维问题。

### 1.2 弱形式与离散

`M dT/dt + (K_cond + H_conv) T = f_conv + P(t) f_heat_unit`，单元矩阵全部解析积分：

| 项 | 表达式 |
|---|---|
| 刚度 | `K_e = k·Ae·(∇N_i·∇N_j)` |
| 一致质量 | `M_e = ρc·Ae/12·(1+δ_ij)` |
| Robin 边界 | `H_e = h·L/6·[[2,1],[1,2]]`，`f_conv_e = h·T_amb·L/2·[1,1]` |
| 体积热源 | `f_heat_e = q'''·Ae/3·[1,1,1]` |

网格采用**交替对角线（checkerboard）三角形剖分**，每层 `ny_per_layer` 行，层界面对齐网格线，热源边界要求落在网格线上（脚本断言检查）。时间积分用 θ 法，稀疏 LU 分解一次复用；θ=1（BE）稳定一阶，θ=0.5（CN）二阶。

### 1.3 Cauer 热阻网络

界面节点格式：每层 N 节，每节 `r=L/(N k W)`、`c=ρc L W/N`，界面节点热容取相邻半节之和，底界面经 `R_conv=1/(hW)` 接环境，顶界面绝热，热源按梯形权重分配到芯片层各节两端。状态方程 `dT/dt = A T + b(P)`，分段常数功率下用增广矩阵指数精确推进（`[T;1] ← expm([[A,b],[0,0]]·Δt)[T;1]`），**无时间离散误差**。

### 1.4 关于 FEniCSx 的替代（如实标注）

提案指定 FEniCSx，但 `fenics-dolfinx` 在 Windows / Python 3.12 无官方 wheel（清华 PyPI 镜像实测 `No matching distribution found`）。本项目改以「手写 Galerkin FEM + scikit-fem 独立装配 + Cauer 网络 + 解析解」四重路线实现，弱形式、单元矩阵、装配与时间离散全部显式可查；scikit-fem 的逐位一致结果证明手写装配与成熟 FEM 内核等价。FEniCSx 原生复现列入 v1.1。

## §2 四重验证链

### 2.1 稳态

| 口径 | 结温 [°C] | 与 FEM 差 [K] |
|---|---|---|
| 手写 FEM（2025 节点 / 3840 单元） | 98.0970 | — |
| 一维解析解（体积热源） | 98.0962 | −0.0008 |
| scikit-fem 12（独立装配） | 98.0970 | −0.0000 |
| 精细 Cauer N=64 | 98.0962 | −0.0008 |
| 朴素串联热阻（表面热源口径） | 98.4423 | +0.3453 |

FEM↔解析最大节点误差 `8.436e-04 K`（线性元对芯片层抛物线温度场的正常 O(h²) 离散误差）；FEM↔skfem `9.742e-11 K`（浮点舍入级）；能量守恒 `3.491e-13`。

**方法学发现（体积热源口径）**：FEM 与 Cauer 一致给出 98.0962 °C，而朴素串联热阻公式 `T_amb + P'(Σ L/(kW) + 1/(hW))` 给出 98.4423 °C。差值恰为 `q''·L_die/(2k_die) = 0.3462 K`：芯片层内均匀体积热源使热流从底面 q'' 线性降到顶面 0，层内温升只有 `q''L/(2k)`，等效热阻是 `L/(2kW)` 而非 `L/(kW)`。工程上若直接套用表面热源公式会系统性高估结温。

### 3.1 热阻分解与 k/h 响应面

基准工况稳态热阻构成：**对流 82.08% / TIM 16.42% / 芯片层半热阻 0.47% / 基板 1.03%**。

## §6 深化 A：轴对称三维扩散热阻与集总网络修正

### 6.1 几何映射（保证与 v1.0 严格可比）

v1.0 的二维模型是「单位厚度、宽 W=10 mm」的条形，线功率 P'=3000 W/m，面热流密度 q''=P'/W=3×10⁵ W/m²。v1.1 把它映射成半径 R=W/2=5 mm 的圆柱叠层：

- 保持 q'' 与三层厚度/物性不变，总功率 P=q''·πR²=23.562 W；
- 顶面热源为半径 a 的圆盘，q=a/R；q=1 时严格一维；
- 一维绝对热阻 R_1D=(Σ L/k + L_die/(2k_die) + 1/h)/(πR²)=3.1023 K/W，T_j,1D=98.0962 °C。

因此两种几何在 q=1 时**必须给出同一个结温**，这成为轴对称装配的强校验。

### 6.2 轴对称 P1 弱形式（所有积分解析精确）

对 dV=2πr dr dz 积分，底部 Robin、其余面自然绝热：

```
∫ 2πr k ∇T·∇v dA + ∫_Γ 2πr h T v dr = ∫ 2πr q''' v dA + ∫_Γ 2πr h T_amb dr
```

线性三角形上 r 线性，故（Ae 为单元面积，r̄ 为重心半径，r_tot=Σr_i）：

| 项 | 表达式 |
|---|---|
| 刚度 | `2π r̄ k Ae (∇N·∇Nᵀ)`，因 `∫r dA = Ae·r̄` 精确 |
| 一致质量 | `2π ρc Ae/60 · M̃`，`M̃_ii=4r_i+2r_tot`，`M̃_ij=r_tot+r_i+r_j` |
| 底边 Robin | `∫r N_i N_j dr` 按 r 线性精确积分（**不用中点近似**） |
| 热源 | `2π q''' Ae/12 · (r_tot+r_i)`，单元求和恰为 `2π q''' Ae r̄` |

**守恒自验**（单测锁死）：单位功率载荷积分 = 1.000000000 W；`M` 全矩阵求和 = Σ ρc_L πR² L_L = 0.3412555 J/K；`K·1` 求和 = h·πR²；`f_conv` 求和 = h·T_amb·πR²。

### 6.3 装配验证与网格收敛

| 项 | 结果 |
|---|---|
| q=1 结温（轴对称 FEM / 一维解析） | 98.0959 / 98.0962 °C，误差 **−2.63×10⁻⁴ K** |

### 6.5 两参数闭合式（4 点标定 / 5 点留一验证）

定义「有效散热面积指数」γ(q)，令总热阻 `R_total = R_1D · q^(−γ(q))`：

```
R_sp(q) = R_1D [ q^(−γ(q)) − 1 ],    γ(q) = g0 + g1 (1−q)
γ_obs(q) = ln(1 + R_sp/R_1D) / ln(1/q)
```

γ_obs 在 q=0.9→0.15 从 0.314 单调增到 0.479 且近乎线性；g0=0.29548、g1=0.23476 由 q∈{0.8,0.6,0.4,0.2} 四点线性最小二乘标定，其余 5 点留一验证：

## §7 深化 B：非线性物性、脉冲波形与 θ 法

### 7.1 k(T) 的误差边界

`k(T)=k0[1+α(T−T_amb)]`，逐单元取重心温度，Picard + 欠松弛 ω=0.7（α=0 时 ω=1 一步收敛，回归误差 0 K）。

| α [1/K] | −0.005 | −0.003 | −0.001 | 0 | +0.001 | +0.003 |
|---|---|---|---|---|---|---|
| 结温 [°C] | 105.162 | 101.468 | 99.038 | 98.097 | 97.285 | 95.947 |
| 相对常物性 [K] | +7.065 | **+3.371** | +0.941 | 0 | −0.813 | −2.150 |

Si 在 300–400 K 的 k 约以 α≈−0.003/K 下降，**常物性假设低估结温 3.37 K（占温升 4.6%）**。因对流热阻占 82%，误差被稀释但不可忽略；若换热强化（h 提高）该比例会放大。

### 7.2 一阶 RC 周期方波闭式解与能量守恒不变量

单节 RC 在周期方波下的精确稳态（`a=D·T/τ`，`b=(1−D)·T/τ`）：

```
T_high = T_amb + P·R (1−e^(−a)) / (1−e^(−(a+b)))
T_low  = T_amb + (T_high − T_amb) e^(−b)
T_avg  = T_amb + D·P·R          （能量守恒，与 T 无关）
```

闭式解与单节 BE 数值积分在 D=0.2/0.5/0.8 全部吻合到 <0.01 K（单测锁死）。更重要的是 **T_avg 不变量**：FEM 六档占空比的周期平均温度与 `T_amb+D·P·R` 最大偏差仅 **0.153 K**，与精细 Cauer 峰值最大差 **0.0435 K**——两条独立求解链再次互证。

## §8 深化 C：k_TIM / h 反辨识与可辨识性

### 8.1 精确阶跃响应（模型降阶工具）

Cauer 网络状态方程 `C dT/dt = −G T + b`，G 对称、C=diag(caps)。对称化 `S=C^(−1/2) G C^(−1/2)=VΛVᵀ` 后：

```
e^(At) = C^(−1/2) V diag(e^(−λt)) Vᵀ C^(1/2)
T(t)   = T_ss + e^(At)(T_0 − T_ss),   T_ss = G^(−1) b
```

一次 `eigh` 即可求任意多时刻温度，单次正演 ~6 ms，使上百次最小二乘反演在秒级完成。与增广矩阵 expm 逐步推进差 **9.76×10⁻⁵ K**（单测锁死）。

### 8.2 Fisher 信息矩阵

θ=[ln k_TIM, ln h]，真值 (5.0, 5000.0)：

| 观测集 | 点数 | FIM 秩 | 条件数 | corr(ln k, ln h) |
|---|---|---|---|---|
| 仅稳态（3 个功率点） | 3 | **1** | **1.15×10¹⁷** | +1.000 |
| 阶跃 + 顶面测点 | 40 | 2 | 17.94 | −0.733 |
| 阶跃 + 顶/底双测点 | 80 | 2 | 19.66 | **−0.501** |

稳态数据只能辨识 R_total，FIM 秩 1 → **结构性不可辨识**。阶跃早期段提供第二个独立时间常数，秩 2；加底面测点主要把参数相关性从 −0.73 降到 −0.50（条件数反而略升）。

**退化谷的直接证据**：稳态数据从 4 个不同初值出发，收敛到 k_TIM=3.31/4.15/6.97/11.94、h=5569/5213/4733/4479 四组完全不同的解，**代价全部为 0**。损失面左图是沿双曲线的零误差谷，右图（阶跃）才出现明确椭圆极小值。

### 8.3 噪声放大与测点建议

4 档测量噪声 × 20 次 Monte Carlo，线性化 FIM 协方差预测的 1σ 相对误差与实测散布平均相差 **8.4%**（验证线性化有效）。σ=0.5 K 时：

| 观测集 | k_TIM 1σ 散布 | h 1σ 散布 |
|---|---|---|
| 顶面单测点 | 1.48% | 0.71% |
| 顶/底双测点 | **1.20%** | **0.41%** |

**结论**：稳态标定无法分离 k_TIM 与 h（呼应 A5 项目的两节点热网络结构性不可辨识）；必须做阶跃激励并采样早期段；测点布在 TIM 两侧（顶 + 底）可进一步压低相关性。工程测量规格建议：σ ≤ 0.1 K、采样覆盖 2 ms–5 s、至少双测点。

## §10 方法与实现

### 10.1 E13：k(T) 瞬态耦合的完整 Newton 切线与离散能量守恒恒等式

v1.1 的 `solve_nonlinear_steady` 只做**稳态** Picard。本轮把温度相关导热系数推进到瞬态 θ 法，`α=0` 时严格退化为 v1.0 `run_transient`：

```
R(T) = M/Δt (T − Tⁿ) + θ[K_c(T)+H]T + (1−θ)[K_c(Tⁿ)+H]Tⁿ
       − θ fⁿ⁺¹ − (1−θ) fⁿ = 0
k_e(T) = k0_e [1 + α(T̄_e − T_ref)]，T̄_e 为单元重心温度
```

关键是**不能冻结 K**：`∂k_e/∂T_j = k0_e α/3 (j∈e)`，故

```
d[K_c(T)T]/dT = K_c(T) + D,
D[tri_i, tri_j] += (k0_e α/3) (G_e T_e)_i,   G_e = A_e ∇N·∇Nᵀ
J = M/Δt + θ[H + K_c(T) + D]
```

这是完整 Newton（非简化/弦截 Newton）；单测用中心差分逐列校验 `J[:,j]`，相对误差 <2e-5。

**离散能量守恒恒等式**（本轮的方法学收获）：P1 拉普拉斯刚度对称且行和为零、`1ᵀ(H T − f_conv) = h∫(T−T_amb)ds`、`1ᵀf_heat_unit = 1 W/m`，三者相消给出

```
1ᵀR(T) ≡ ΔU/Δt + Q_conv − Q_in       （恒等，与迭代是否收敛无关）
```

即**把残差向量求和就得到能量失衡**，无需额外装配，可作为免费的收敛诊断。相对残差必须用额定功率归一化：关断相 `Q_in=0`，若拿本步 `Q_in` 当分母会把机器噪声放大成天文数字（实测误报 126 倍，已修）。

### 10.2 E14：单极点动态扩散热阻与留一可辨识性检验

v1.1 把扩散区当作零热容热阻 `T_j = T_1D + P(t)R_sp`，慢脉冲极准、快脉冲把摆幅高估到 +73.6%。本轮给它补一个一阶极点：

```
C_sp d(ΔT)/dt = P(t) − ΔT/R_sp ,   T_j = T_1D,top + ΔT ,   τ = R_sp C_sp
A_aug = diag(−1/τ, A_Cauer),  b_aug(P) = [P/C_sp ; b_Cauer(P)]
```

仍用增广矩阵指数 `expm` 精确推进（无时间离散误差）。静态极限 `ΔT=P·R_sp` 与 v1.1 严格一致；`t=0` 两者的差异是**物理定义差异**（静态模型瞬间跳到 `P·R_sp`，动态极点需要充电），单测分 `t=0` / `t>0` 断言。

单极点是否够用是**可证伪命题**：逐周期用 FEM 摆幅二分标定 `τ_best`，若它随周期漂移，说明 constriction 区是分布参数系统；再用单一周期标定的 `τ_fixed` 做留一预测量化泛化误差。为严格可比，直接复用 v1.1 同协议的轴对称 FEM 真值（`dt=min(0.005,T/40)`、`t_end=max(6T,0.4)`），不重跑昂贵 FEM。

### 10.3 E15：四次非线性辐射边界与「等温升功率」协议

底面追加净辐射热流 `q_rad(T)=εσ(T_K⁴−T_amb,K⁴)`，沿边用 **3 点 Gauss** 装配残差与切线雅可比（T 沿边线性 ⇒ T⁴ 为四次、T³N_iN_j 为五次，3 点 Gauss 对五次以下精确，故无积分误差）。T⁴ 强非线性下 Newton 加残差下降式折半线搜索。对照工程常用的「环境温度处线性化」`h0=4εσT_amb³`；精确割线系数为 `h_rad(T)=εσ(T²+T_amb²)(T+T_amb)`。

接触热阻以面积比热阻 `r_c'' [m²K/W]` 串入 TIM 层，折算 `k_eff = L/(L/k + r_c'')`，从而复用已验证的 FEM 装配链，并与 1D 解析式互证。

**协议修正**：若把默认 `P'=3000 W/m` 直接配到 `h=10 W/(m²K)`，无辐射温升会达到数万 K（非物理）。故采用等温升功率 `P' = 300 K / R_conv × scale`，使各 `h_conv` 下无辐射基准温升一致，干净分离 `h_rad/h_conv` 的比值效应。

### 10.4 工程：单元几何缓存（性能）

E13 首版每步两次逐单元 Python 循环装配（576 单元 × 600 步 × 32 组），单组实验需 14 分钟且 `run_all.sh` 不可实用。把 `G_e=A_e∇N·∇Nᵀ` 与 COO 索引（`rows=repeat(elems,3)`、`cols=tile(elems,3)`，K 与 D 共用）预计算一次，装配改为纯向量化 COO 构造；新增单测锁定「缓存复用 ≡ 每次重建 ≡ v1.1 装配器」。全量 pytest 从 41.8 s 降到 **18.7 s**，E13 单组 Newton 4.3 s / Picard 29.8 s。

## §11 结果

### 11.1 E13：Newton 快 7 倍，能量守恒残差是免费诊断

网格 325 节点（`nx=24`、`ny_per_layer=4`），`dt=0.01 s`、`t_end=6 s`（3 个周期）、θ=1。

| α [1/K] | 峰值结温 [°C] | 相对常物性 [K] | Newton 迭代 | Picard 迭代 | 加速比 |
|---:|---:|---:|---:|---:|---:|
| −0.005 | 86.438 | **+4.075** | 1261 | 9022 | 7.2× |
| −0.003 | 84.470 | +2.107 | 1244 | 9013 | 7.2× |
| −0.001 | 82.982 | +0.619 | 1225 | 9007 | 7.4× |
| 0 | 82.363 | 0 | 600 | 600 | 1× |
| +0.001 | 81.808 | −0.555 | 1220 | 9014 | 7.4× |
| +0.003 | 80.851 | −1.511 | 1234 | 9021 | 7.3× |
| +0.005 | 80.055 | **−2.308** | 1240 | 9021 | 7.3× |

- α<0（k 随温升下降）使常物性**低估**结温，方向与 v1.1 稳态结论一致；但数值不同（v1.1 常功率稳态 α=−0.003 为 3.37 K，此处周期峰值 2.107 K），因口径是脉冲周期峰值而非常功率稳态，两者不可直接比较。
- Newton 每步最多 3 次迭代（均值 ≈2），欠松弛 Picard 需 ≈15 次（最多 16 次）。强非线性 α=−0.010 时 Newton 1613 次（max 4/步）vs Picard 9335 次（max 17/步），峰值同为 **97.2365 °C**。α=−0.012 时两者都因 `k(T)≤0` 终止——这是**物性外推的物理边界**，不是算法失败，如实留档。
- **独立交叉验证**：常功率 `t_end=12 s`（≫11τ）下瞬态终值 101.47120 °C，v1.1 独立实现的稳态 Picard 为 101.47131 °C，差 **−1.13e-4 K**。两条装配/求解链互证。
- **能量审计**：收敛解 `max|1ᵀR| ≈ 1e-9 W/m`（相对 3e-13）；把非线性迭代人为截断到 1 次则跳到 **1800 W/m**（相对 0.6），放大约 **2×10¹² 倍**。Picard 收敛解的残差约 1e-7 W/m，比 Newton 大 ~100 倍（欠松弛留下的余量）。
- tol 从 1e-4 放到 1e-10：迭代数 1200→1382，能量残差始终 ~1e-9 —— Newton 二次收敛使能量守恒对容差**不敏感**，只有真正未收敛才会破坏它。dt 扫描 0.02→0.0025 s 时每步最大迭代数恒为 3，峰值从 86.349 收敛到 86.505 °C（Δ=0.156 K）。

### 11.2 E14：单极点假设被证伪，但绝对误差确有小幅改善

`q=a/R=0.2`、`R_sp=3.5967 K/W`、物理 `τ_spread=R_sp·C_sp=5.5932 ms`（`C_sp=1.5551e-3 J/K`）、总功率 23.56 W、Cauer N=64。

| T [s] | T/τ_spread | τ_best [ms] | τ_best/τ_phys | 静态摆幅误差 | 动态(单一 τ)摆幅误差 | 静态峰值误差 [K] | 动态峰值误差 [K] |
|---:|---:|---:|---:|---:|---:|---:|---:|
| 2.00 | 357.6 | 129.78 | 23.20 | +0.06% | +0.06% | +0.04 | +0.04 |
| 0.50 | 89.4 | 28.76 | 5.14 | +0.03% | +0.03% | +0.02 | +0.02 |
| 0.20 | 35.8 | **16.83** | 3.01 | +0.54% | −0.00% | +0.32 | +0.02 |
| 0.10 | 17.9 | 13.22 | 2.36 | +4.61% | −5.29% | +2.24 | −2.56 |
| 0.05 | 8.9 | 10.37 | 1.85 | +18.61% | −23.00% | +6.32 | −7.97 |
| 0.02 | 3.6 | 7.61 | 1.36 | **+73.62%** | **−47.78%** | +19.07 | −12.12 |

- **核心负结果**：`τ_best` 随周期单调从 129.78 ms 掉到 7.61 ms，漂移 **17.06×**（相对物理 τ 从 23.2 倍降到 1.36 倍）。慢脉冲下摆幅对 τ 几乎不敏感（τ 不可辨识），快脉冲下 τ 才接近物理值 —— 说明扩散区**不是单极点**而是分布参数系统。以 T=0.2 s 标定的 `τ_fixed=16.83 ms`（3.01× 物理值）做留一预测，最大摆幅误差 **47.78%**、RMSE 23.83%、最大峰值误差 12.12 K。
- 动态 RC 的**绝对**误差确有改善：T=0.02 s 摆幅误差 73.62%→47.78%（−35%），峰值误差 19.07 K→12.12 K（−36%），但误差方向由**高估翻转为低估**，且仍远超 1% 工程阈值。
- **1% 有效边界没有下推**：静态 0.2 s、动态(单一 τ) 仍 0.2 s；只有逐周期重标定的理论下界能到 0.02 s（不可泛化，属过拟合）。未修正一维 Cauer 的摆幅误差为 −66.9%~−94.8%，说明补 R_sp 这一步本身仍是必要的大头。
- 结论：给扩散区补**一个** RC 节只搬走了「高估」，没解决快脉冲；真正的修法需要多极点/分布参数模型（Foster 多节、卷积核或直接从 FEM 抽取传递函数）。

### 11.3 E15：辐射是「自然对流问题」，接触热阻比 TIM 本体重要 28 倍

`h_rad` 在环境温度处（ε=0.9）仅 **5.41 W/(m²K)**；随温度升高按 T³ 增长，高温时割线系数显著更大。

| h_conv [W/(m²K)] | ε=0.9 辐射占比 | 精确 Newton 结温 [°C] | 无辐射结温 [°C] | 线性化结温误差 [K] | Newton 迭代 |
|---:|---:|---:|---:|---:|---:|
| 10 | **51.85%** | 169.6 | 325.1 | +50.21 | 6 |
| 50 | 23.61% | 254.8 | 325.7 | +41.55 | 5 |
| 500 | 3.77% | 320.3 | 331.5 | +8.09 | 4 |
| 5000 | **0.41%** | 389.3 | 390.5 | +0.89 | 3 |

（表中为 scale=1；scale=2 时辐射占比上限 61.12%、降温 366.72 K、线性化误差最大 **+171.47 K**。）

- **预设成立**：强制对流 h=5000 下辐射占比上限 1.06%（含 scale=2），降温最多 6.37 K，属伪需求；log-log 斜率 −0.790，5% 显著性阈值落在 **h_conv ≈ 266 W/(m²K)** —— 只有自然对流/弱强制对流/近真空封装才需计入辐射。
- 「环境温度处线性化」**系统性低估散热、高估结温**（误差恒为正），在辐射主导工况可达 171.47 K，必须用精确 Newton 或至少局部更新 `h_rad(T)`。全部 32 组 Newton 均收敛（3–6 次），能量守恒 `Q_conv + Q_rad = P'` 误差 **0.0**（机器精度）。
- **接触热阻 vs TIM 本体**：`ΔT = 3.0e5 · r_c''`（K），完全线性；`r_c''=1e-5` 已让结温 +3.0 K，`1e-3` 时 TIM 等效 k 掉到 0.192 W/(mK)、结温 398.1 °C（+300 K）。而把 TIM 本体从 5 做到 50 W/(mK) 的全部收益只有 **10.80 K**（98.099→87.299 °C）。
- **临界接触热阻 `r_c'' ≈ 3.60e-5 m²K/W`** 即可把 TIM 本体的全部优化收益抵消；最大接触恶化是 TIM 收益的 **27.78 倍**。工程优先级：先控界面（TIM 涂覆/压力/粗糙度），再谈本体导热。

## §12 v1.2 结论与剩余未做项

### 12.1 十个可复用结论

1. k(T) 瞬态必须装配完整切线 `D`（`∂k_e/∂T_j=k0_eα/3`），冻结 K 的简化 Newton 不是等价替代；单测以中心差分锁定。
2. Newton 比欠松弛 Picard 少 **7.2×** 迭代（强非线性 5.8×），且峰值解完全一致。
3. `1ᵀR ≡ ΔU/Δt + Q_conv − Q_in`：**残差求和即能量失衡**，截断迭代放大 2×10¹² 倍，是零成本的收敛诊断。
4. 常功率瞬态终值与 v1.1 稳态 Picard 差 1.13e-4 K，两条独立求解链互证；α<0 时脉冲峰值可比重物性高 4.08 K。
5. α≤−0.012 时 `k(T)≤0` 是物性模型外推边界，不是数值发散。
6. **单极点扩散修正被证伪**：τ_best 跨周期漂移 17.06×，留一摆幅误差 47.78%；扩散区为分布参数系统。
7. 动态 RC 把 T=0.02 s 的摆幅/峰值绝对误差分别降 35%/36%，但误差由高估翻为低估，1% 有效边界仍停在 T=0.2 s。
8. `h_rad≈5.4 W/(m²K)` ⇒ 强制对流下辐射是伪需求；5% 阈值约 h_conv=266 W/(m²K)。
9. 环境温度处线性化辐射在辐射主导工况高估结温达 171.47 K；精确 Newton 3–6 次收敛且能量守恒到机器精度。
10. 接触热阻的边际代价是 TIM 本体优化的 27.78 倍；临界 `r_c''=3.60e-5 m²K/W`。
