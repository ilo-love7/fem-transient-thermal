# 有限元瞬态热仿真：芯片/功率器件散热分析 — 基准评测报告（N6 v1.0.0）

> 博远线上科研提案 N6 ｜ 传热 / 半导体热管理 ｜ 数值仿真 ｜ 2026-11-10
> 环境：Windows / Python 3.12.10 / NumPy 2.5.4 / SciPy 1.18.1 / scikit-fem 12.0.2 / Matplotlib 3.11.2，纯 CPU

## 摘要

从零实现二维 Galerkin 有限元瞬态热传导求解器（多层结构、Robin 对流、脉冲体积热源、θ 法时间积分），并建立**解析解 / 第三方 FEM / 精细 Cauer 热阻网络 / 单节集总 Cauer** 四重交叉验证。

核心结果：

1. **装配正确性**：手写 FEM 与 scikit-fem 12 独立装配的稳态温度场逐位一致（最大节点差 **9.7e-11 K**）；与一维解析解差 **8.4e-4 K**；稳态能量守恒相对误差 **3.5e-13**。
2. **提案目标达成**：FEM 与精细 Cauer 网络在脉冲激励下的结温曲线**峰值温升误差 0.065%、摆幅误差 0.181%**，远优于提案「与热阻网络解析解误差 <5%」的目标。
3. **数值方法收敛阶**：时间后向 Euler `p=1.02`（理论 1）、Crank–Nicolson `p=2.01`（理论 2）、空间几何相似加密 `p=2.03`（理论 2）。
4. **口径发现**：芯片层为均匀体积热源时，朴素串联热阻公式高估结温 **0.3462 K**（层内热流线性递减使该层等效热阻减半）。
5. **工程结论**：基准工况热阻由对流主导（82.08%）；组合强化方案把周期稳态结温峰值从 82.41 °C 压到 **41.26 °C（−49.9%）**。
6. **适用边界**：一维集总 Cauer 网络在慢脉冲（T≥0.1 s）下误差 <3%，但在快脉冲（T=0.02 s）下摆幅误差 8.8%；二维局部热源 w/W=0.2 时因扩散热阻占 31.1% 而**低估结温 22.84 K**。

## §1 物理模型与数值方法

### 1.1 控制方程与边界

二维单位厚度模型（所有功率以线密度 W/m 给定）：

```
ρc ∂T/∂t = ∇·(k ∇T) + q'''(x, y, t)
底面 y=0： -k ∂T/∂n = h (T − T_amb)      （Robin 对流）
顶面 y=H、左右侧面：绝热（自然边界）
```

三层结构自底向上：Cu 基板（1.0 mm, k=400, ρc=3.45e6）、TIM（0.2 mm, k=5, ρc=2.0e6）、Si 芯片（0.3 mm, k=130, ρc=1.65e6）；宽度 10 mm，`P'=3000 W/m`，`h=5000 W/(m²K)`，`T_amb=25 °C`。热源位于芯片层中心区域，`heat_source_width=W` 时退化为严格一维问题。

### 1.2 弱形式与离散

`M dT/dt + (K_cond + H_conv) T = f_conv + P(t) f_heat_unit`，单元矩阵全部解析积分：

| 项 | 表达式 |
|---|---|
| 刚度 | `K_e = k·Ae·(∇N_i·∇N_j)` |
| 一致质量 | `M_e = ρc·Ae/12·(1+δ_ij)` |
| Robin 边界 | `H_e = h·L/6·[[2,1],[1,2]]`，`f_conv_e = h·T_amb·L/2·[1,1]` |
| 体积热源 | `f_heat_e = q'''·Ae/3·[1,1,1]` |

网格采用**交替对角线（checkerboard）三角形剖分**，每层 `ny_per_layer` 行，层界面对齐网格线，热源边界要求落在网格线上（脚本断言检查）。时间积分用 θ 法，稀疏 LU 分解一次复用；θ=1（BE）稳定一阶，θ=0.5（CN）二阶。

### 1.3 Cauer 热阻网络

界面节点格式：每层 N 节，每节 `r=L/(N k W)`、`c=ρc L W/N`，界面节点热容取相邻半节之和，底界面经 `R_conv=1/(hW)` 接环境，顶界面绝热，热源按梯形权重分配到芯片层各节两端。状态方程 `dT/dt = A T + b(P)`，分段常数功率下用增广矩阵指数精确推进（`[T;1] ← expm([[A,b],[0,0]]·Δt)[T;1]`），**无时间离散误差**。

### 1.4 关于 FEniCSx 的替代（如实标注）

提案指定 FEniCSx，但 `fenics-dolfinx` 在 Windows / Python 3.12 无官方 wheel（清华 PyPI 镜像实测 `No matching distribution found`）。本项目改以「手写 Galerkin FEM + scikit-fem 独立装配 + Cauer 网络 + 解析解」四重路线实现，弱形式、单元矩阵、装配与时间离散全部显式可查；scikit-fem 的逐位一致结果证明手写装配与成熟 FEM 内核等价。FEniCSx 原生复现列入 v1.1。

## §2 四重验证链

### 2.1 稳态

| 口径 | 结温 [°C] | 与 FEM 差 [K] |
|---|---|---|
| 手写 FEM（2025 节点 / 3840 单元） | 98.0970 | — |
| 一维解析解（体积热源） | 98.0962 | −0.0008 |
| scikit-fem 12（独立装配） | 98.0970 | −0.0000 |
| 精细 Cauer N=64 | 98.0962 | −0.0008 |
| 朴素串联热阻（表面热源口径） | 98.4423 | +0.3453 |

FEM↔解析最大节点误差 `8.436e-04 K`（线性元对芯片层抛物线温度场的正常 O(h²) 离散误差）；FEM↔skfem `9.742e-11 K`（浮点舍入级）；能量守恒 `3.491e-13`。

**方法学发现（体积热源口径）**：FEM 与 Cauer 一致给出 98.0962 °C，而朴素串联热阻公式 `T_amb + P'(Σ L/(kW) + 1/(hW))` 给出 98.4423 °C。差值恰为 `q''·L_die/(2k_die) = 0.3462 K`：芯片层内均匀体积热源使热流从底面 q'' 线性降到顶面 0，层内温升只有 `q''L/(2k)`，等效热阻是 `L/(2kW)` 而非 `L/(kW)`。工程上若直接套用表面热源公式会系统性高估结温。

### 2.2 脉冲瞬态（T=2 s，duty=0.5，dt=0.005 s，t_end=10 s）

| 方法 | 峰值 [°C] | 谷值 [°C] | 摆幅 [K] |
|---|---|---|---|
| FEM-BE | 82.455 | 40.641 | 41.813 |
| FEM-CN | 82.448 | 40.648 | 41.801 |
| Cauer-N64 | 82.492 | 40.603 | 41.889 |
| Cauer-N1 | 82.489 | 40.607 | 41.882 |

| 对比 | 峰值误差（温升口径） | 摆幅误差 | RMSE/幅值 |
|---|---|---|---|
| FEM-BE vs Cauer-N64 | **0.0651%** | 0.1805% | 0.1183% |
| FEM-CN vs Cauer-N64 | 0.0760% | 0.2107% | 0.2622% |
| Cauer-N1 vs Cauer-N64 | 0.0057% | 0.0158% | 0.1485% |
| Cauer-N8 vs Cauer-N64 | 0.0001% | 0.0002% | 0.0023% |

> 注：峰值温度是绝对量（含 25 °C 环境温度），直接以其为分母会把误差压小约 `(T_peak−T_amb)/T_peak` 倍，故统一采用**温升口径**。瞬态热容分布失真最敏感的指标是**摆幅误差**。

**提案目标 <5% 达成，且裕度约 2 个数量级。**

### 2.3 收敛阶

| 项目 | 拟合阶 p | 理论阶 | 误差序列（粗→细） |
|---|---|---|---|
| 时间 BE | 1.02 | 1 | 1.83e-1, 9.75e-2, 4.93e-2, 2.38e-2, 1.07e-2 |
| 时间 CN | 2.01 | 2 | 3.01e-2, 7.52e-3, 1.88e-3, 4.66e-4, 1.13e-4 |
| 空间（几何相似加密 nx/npl 同步） | 2.03 | 2 | 1.60e-2, 3.71e-3, 9.08e-4, 2.26e-4, 5.66e-5 |

时间收敛实验采用**平滑 ramp 功率** `P(t)=P'(1−e^{−t/0.05})`：恒定功率阶跃会在 t=0 制造初值层，污染 CN 的二阶收敛（实测会把拟合阶虚高到 3.84）。空间收敛采用 (nx, npl) = (10,2)→(160,32) 几何相似加密。

Cauer 精细度扫描（参考 N=128）：N=1 峰值误差 0.0037%、N=8 已降到 0.0001%，低频工况下 N≥8 即收敛。

## §3 参数扫描与散热设计

### 3.1 热阻分解与 k/h 响应面

基准工况稳态热阻构成：**对流 82.08% / TIM 16.42% / 芯片层半热阻 0.47% / 基板 1.03%**。

扫描 `k_TIM ∈ {1,2,5,10,20,50} W/(m K)` × `h ∈ {500…50000} W/(m²K)` 共 42 组（每组 FEM 稳态 + 8 s 脉冲瞬态），输出稳态结温与摆幅响应面（`figures/heatmap_*.png`）。

- `k_TIM` 从 1→50 的**绝对**结温降恒为 58.80 K（串联热阻可加，与 h 无关，解析可证）；
- 但**相对**降幅随强化对流从 8.57%（h=500）放大到 63.85%（h=50000）——对流瓶颈被削掉后，TIM 导热升级才成为决定性手段。

### 3.2 散热方案对比

| 方案 | 稳态结温 [°C] | 周期稳态峰值 [°C] | 摆幅 [K] | 峰值降幅 |
|---|---|---|---|---|
| 基准 | 98.10 | 82.41 | 41.73 | — |
| 强化对流 h×4 (20000) | 53.10 | 52.84 | 27.57 | 35.89% |
| 高导热 TIM k×10 (50) | 87.30 | 72.48 | 32.67 | 12.05% |
| 减薄 TIM L/4 (0.05 mm) | 89.10 | 75.11 | 36.13 | 8.86% |
| **组合优化** | **41.40** | **41.26** | **16.12** | **49.93%** |

单项中强化对流最有效；三项组合近似叠加但非线性（热阻串联 + 热容变化影响摆幅）。

### 3.3 二维扩散热阻（集总网络的失效边界）

热源宽度从铺满（w/W=1）收窄到 0.2：

| w/W | 2D 稳态结温 [°C] | 1D 解析 [°C] | R_spread/R_1D | Cauer 峰值低估 [K] |
|---|---|---|---|---|
| 1.00 | 98.10 | 98.10 | 0.00% | 0.00 |
| 0.80 | 100.98 | 98.10 | 3.93% | 2.89 |
| 0.60 | 105.20 | 98.10 | 9.67% | 7.10 |
| 0.40 | 111.43 | 98.10 | 18.15% | 13.33 |
| 0.20 | 120.94 | 98.10 | **31.11%** | **22.84** |

局部热源产生横向扩散热阻，一维集总网络无法表示；w/W=0.2 时低估结温 22.84 K（温升口径 +31%）。**结论：Cauer 网络的 <5% 一致性仅在准一维（热源铺满或近似铺满）条件下成立。**

## §4 集总 Cauer 的瞬态适用边界

脉冲周期扫描（h=5000，精细 N=64 为参考）：

| 周期 [s] | 精细摆幅 [K] | 集总摆幅 [K] | 相对误差 |
|---|---|---|---|
| 0.02 | 2.8031 | 2.5566 | **8.796%** |
| 0.05 | 5.5505 | 5.1987 | **6.338%** |
| 0.1 | 8.8941 | 8.6409 | 2.847% |
| 0.2 | 11.4099 | 11.5033 | 0.818% |
| 0.5 | 16.9023 | 16.8604 | 0.248% |
| 1 | 26.4009 | 26.3734 | 0.104% |
| 2 | 41.8848 | 41.8782 | 0.016% |
| 5 | 66.0383 | 66.0468 | 0.013% |

**5% 目标线落在 T≈0.06–0.1 s**。同时扫描 `h=100…500000`（Bi_TIM 0.004→20）：T=0.02 s 的摆幅误差仅从 8.77% 变到 9.33%，几乎不随外部对流变化。

> **物理结论**：经典 `Bi<0.1` 是**稳态集总**判据（层内温度均匀性）；本项目表明**瞬态集总模型的失真由脉冲周期与层内扩散时间之比 `T/τ_layer` 主导**（`τ_TIM≈0.016 s`，T=0.02 s 与之同量级即失效），而非外部 Bi 数。工程上用 RC 集总网络做快脉冲热设计前，必须核对脉冲频谱与层内扩散时间尺度。

## §5 结论与展望

### 5.1 交付结论

- 完成提案 N6 全部五项核心方法（控制方程与边界、FEM 弱形式与网格、参数扫描、热阻网络交叉验证、结温曲线与散热方案评估），交叉验证误差 **0.065%** 远优于 <5% 目标；
- 手写求解器经第三方 FEM 库逐位验证，时间与空间收敛阶全部符合理论，16 项单测全绿；
- 额外产出两个可复用方法学结论：体积热源/表面热源的 0.346 K 口径差、瞬态集总网络失效由 `T/τ_layer` 而非 Bi 主导；
- 明确界定 Cauer 网络适用边界（准一维 + 慢脉冲），避免工程误用。
