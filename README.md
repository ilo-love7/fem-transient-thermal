# 有限元瞬态热仿真：芯片/功率器件散热分析（N6）

> 博远线上科研提案 N6 ｜ 传热 / 半导体热管理 ｜ 数值仿真 ｜ v1.2.0 ｜ 2026-11-11

从零手写二维 Galerkin 有限元瞬态热传导求解器，模拟 Si 芯片 / TIM / Cu 基板三层结构在脉冲功率激励下的温度场演化，并与**解析解、第三方 FEM 库、Cauer 热阻网络**四重交叉验证。纯 CPU、无数据集，`run_all.sh` 一键复现。

## 技术路线说明（如实标注）

提案指定 FEniCSx。**`fenics-dolfinx` 在 Windows / Python 3.12 无官方 wheel**（清华镜像实测 `No matching distribution`），故采用等价但更透明的三层路线：

| 角色 | 实现 | 作用 |
|---|---|---|
| 主求解器 | **手写 Galerkin FEM**（纯 NumPy/SciPy） | 弱形式、单元矩阵、装配、时间积分全部显式实现 |
| 独立装配验证 | **scikit-fem 12.0.2**（pip 可装，跨平台） | 独立内核复算同一弱形式，证明手写装配无误 |
| 物理交叉验证 | **Cauer 热阻网络**（精细 N 节 + 单节集总） | 矩阵指数精确解，与 FEM 瞬态曲线对照 |
| 解析基准 | 一维多层稳态解析解 | 热阻串联 + 体积热源抛物线解 |

等效性：稳态 FEM↔skfem 最大节点差 **9.7e-11 K**（逐位一致）；FEM↔精细 Cauer 瞬态峰值温升误差 **0.065%**，远优于提案 <5% 目标。FEniCSx 复现列入 v1.1 展望。

## 方法

- **控制方程**：`ρc ∂T/∂t = ∇·(k∇T) + q'''(x,t)`；底面 Robin 对流 `-k∂T/∂n = h(T−T_amb)`，顶面/侧面绝热。
- **空间离散**：结构化多层矩形网格 + **交替对角线**三角形剖分（消除单向剖分的各向异性锯齿），P1 线性单元；一致质量矩阵 `M_e=ρc·Ae/12·(1+δ)`，刚度 `K_e=k·Ae·∇N_i·∇N_j`，Robin 边界 `H_e=hL/6·[[2,1],[1,2]]`，全部解析积分。
- **时间离散**：θ 法 `(M/Δt+θK)T^{n+1} = (M/Δt−(1−θ)K)T^n + θf^{n+1}+(1−θ)f^n`，θ=1 后向 Euler / θ=0.5 Crank–Nicolson；稀疏 LU 一次分解循环复用。
- **Cauer 网络**：界面节点格式（每节 `r=L/(NkW)`、`c=ρcLW/N`，端节点半容），`dT/dt=AT+b`，分段常数功率用增广矩阵指数 `expm` 精确推进（无时间离散误差）。
- **几何/物性**：10 mm 宽、1.5 mm 厚（Cu 1.0 mm / TIM 0.2 mm / Si 0.3 mm），P'=3000 W/m 线功率，h=5000 W/(m²K)，T_amb=25 °C；二维按单位厚度建模。

## 结果摘要

### 验证链（一维口径，热源铺满）

| 口径 | 稳态结温 [°C] | 说明 |
|---|---|---|
| 手写 FEM | 98.0970 | 2025 节点 / 3840 单元 |
| 一维解析解（体积热源） | 98.0962 | 差 8.4e-4 K |
| scikit-fem 12（独立装配） | 98.0970 | 差 9.7e-11 K |
| 精细 Cauer N=64 | 98.0962 | 稳态与热容离散无关 |
| 朴素串联热阻（表面热源口径） | 98.4423 | **高估 0.3462 K** |

> **方法学发现**：芯片层是均匀体积热源，层内热流从底面 q'' 线性降到顶面 0，故该层温升只有 `q''L/(2k)`，等效热阻 `L/(2kW)`；直接套用「热源集中在表面」的朴素串联热阻公式会高估 0.346 K。

| 瞬态交叉验证（T=2 s, duty=0.5） | 峰值温升误差 | 摆幅误差 | RMSE/幅值 |
|---|---|---|---|
| FEM-BE vs Cauer-N64 | **0.065%** | 0.181% | 0.118% |
| FEM-CN vs Cauer-N64 | 0.076% | 0.211% | 0.262% |
| Cauer-N1 vs Cauer-N64 | 0.006% | 0.016% | 0.149% |

**收敛阶**：时间 BE `p=1.02`（理论 1）、时间 CN `p=2.01`（理论 2）、空间几何相似加密 `p=2.03`（理论 2）。

### 参数扫描与散热设计

- 热阻分解：**对流 82.08% / TIM 16.42% / 芯片层 0.47% / 基板 1.03%**。
- k_TIM 1→50 W/(m K) 的绝对降温恒为 58.80 K，但相对降幅随 h 从 8.57%（h=500）放大到 63.85%（h=50000）——**强化对流后 TIM 才成为主导瓶颈**。
- 散热方案（周期稳态结温峰值）：基准 82.41 °C → 强化对流 52.84 °C（−35.9%）/ 高导热 TIM 72.48 °C（−12.1%）/ 减薄 TIM 75.11 °C（−8.9%）/ **组合优化 41.26 °C（−49.9%）**。
- **集总 Cauer 的适用边界**：慢脉冲 T≥0.1 s 时摆幅误差 <3%；T=0.02 s 时 8.8% 超 5% 线。Bi_TIM 从 0.004→20 误差仅 8.77%→9.33%，说明**瞬态集总失效由脉冲周期 / 层内扩散时间之比主导，而非经典稳态 Bi<0.1 判据**。
- **二维扩散热阻**：热源收窄到 w/W=0.2 时，R_spread 占一维总热阻 **31.1%**，结温 120.94 °C vs 一维 98.10 °C，一维 Cauer **低估 22.84 K** → 集总网络仅适用于准一维/铺满热源场景。

完整数字见 `results/summary_tables.md`，分析见 `reports/基准评测报告-N6.md`。
